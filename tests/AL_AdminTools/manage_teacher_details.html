• Teacher full-access.

• Teacher limited.

Effect to consider ('Remove' tested using support's 'delete' function):

• Groups they are a part of.

  - As current - 'Removed' teacher no longer appears as part of the group.

  - Consider - Currently reinstating teacher put them back into Group they used to be in. Should this be the case?

  - Defect - Deleting group where teacher has been 'removed' bring up warning modal that the removed teacher is still associated with the group.


• Teacher with pending access request if approving teacher is removed

  - As current - Request no longer shown in pending request.


• If user approve access request from removed teacher.

  - Defect - Teacher remain 'deleted', but is given 'Full-access'.

  - Defect - Once approved (And subsequently clicking the approval link in message) user is taken to account details page of the 'removed' teacher. And user is able to edit 'removed' teacher's details.

- Process should be subs send e-mail to purchaser.

- Platform send backup platform message to all teachers with product active.

- Platform does not keep track of purchaser, so if purchaser is removed, cannot assign new user as main contact and update subs?
