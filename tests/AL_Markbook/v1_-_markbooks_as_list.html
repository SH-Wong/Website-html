ALDS User ID

To match your markbook data with the correct student on the site, all students must have their ALDS User ID next to their name in column B of the Markbook Summary sheet.


Retrieving ALDS User ID(s)

•  Go to the Admin tab and choose Manage student details.

•  Use the filters to find the student or group of students.

•  Select the student(s) for which you would like to retrieve the ALDS User ID(s).

•  Click the 'Export selected users' button. This will download a .csv file

   (students_Export.csv) with the ALDS User ID listed against the selected student(s).


Entering the ID(s) into your markbook spreadsheet

• Go to the 'Summary Sheet'.

• Either Copy and paste the correct unique ALDS User ID for each student next to the

   correct name

• Or copy and paste the name(s) and ID(s) into Columns A and B
