The most important thing,  to prevent now is human error:

• Inconsistent unit

• typing mistake

• wrong fields

Large change in values could be realistic depending on:

• Change of production

• Change of energy source


If main purpose is to prevent entry mistake then most likely (and identify-able) mistake would be a missing / additional digit. Hence message re. 10 times change.


Nevertheless, it is not unreasonable to show a simple message if value changes a large amount. (50% ?) Given that a 50% change to any since resource / production is a dramatic change.

Wireframe note:

• Validate upon a pause in input.

• Assumes Anthracite values = 1000 in previous year.

• Shown a warning if a value with a difference of >10 times is entered. (<100, or >10000)

• Assume Electricity (grid) value = 100000 in previous year
